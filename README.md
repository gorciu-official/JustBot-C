# JustBOT-C

An experimental rewrite of [JustBOT](https://github.com/JustcordProjects/JustBot) (a Discord bot for the JustCord server) in kinda modern C. Better than [EclairBOT-C](https://github.com/eclairbakery/EclairBot-c).

![bot image](./docs/assets/readme-image.png)

If you forgot to clone the repo with submodules, please `make submodules` before using any other `make` commands.
